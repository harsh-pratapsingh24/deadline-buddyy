# 📌 Deadline Buddy

Deadline Buddy is a full-stack task and deadline management web application built as part of a Web Development course project. The application allows users to securely manage tasks, track completed and pending work, and stay organized through a dynamic and interactive dashboard.

This project strictly follows the evaluation guidelines provided by the course coordinator and demonstrates real-world usage of frontend, backend, and database technologies.

---

## 🚀 Features

- User authentication (Login / Signup)
- Add, update, delete, and track tasks
- Mark tasks as completed or pending
- Dynamic task dashboard
- Data persistence using MongoDB
- Reusable UI components using EJS templates
- Fully interactive frontend powered by JavaScript

---

## 🛠 Tech Stack

**Frontend**

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository
```bash
git clone https://github.com/harsh-pratapsingh24/deadline-buddyy.git
cd deadline-buddyy
````

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Start MongoDB

* MongoDB Atlas: Ensure internet connection
* Local MongoDB:

```bash
mongod
```

### 4️⃣ Run the application

```bash
npm run dev
```

> Nodemon is used for automatic server reload during development.
